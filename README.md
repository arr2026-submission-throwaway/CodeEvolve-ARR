# CODEEVOLVE-ARR

This repository contains all source code and experimental data for the CodeEvolve ARR submission.

The CodeEvolve-source folder contains the source code of CodeEvolve.

The CodeEvolve-experiments folder contains the experimental results and artifacts for CodeEvolve on all benchmark problems.

The OpenEvolve-experiments folder contains the experimental results and artifacts for OpenEvolve on all benchmark problems.

The ShinkaEvolve-experiments folder contains the experimental results and artifacts for ShinkaEvolve on all benchmark problems.
